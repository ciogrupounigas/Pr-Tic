## Descripción General
**Gestión de Procesos TIC** es el portal que centraliza los procesos críticos del Departamento de Tecnología, asegurando una operación segura, estandarizada y alineada con las políticas corporativas.

## Procesos Documentados
- **Power BI:** Administración de espacios, modelos y permisos.  
- **Ingreso y retiro de personal:** Altas, bajas y control de accesos.  
- **Backups:** Políticas de respaldo, retención y recuperación.  
- **Perfiles ERP:** Roles, permisos y trazabilidad.  
- **Seguridad perimetral:** Firewall, VPN y monitoreo.  
- **Operación y soporte:** Gestión de incidentes, cambios y mantenimiento.

## API de Combustibles Unigas
Interfaz que unifica y homologa los datos maestros con el **ERP SIESA**, facilitando integraciones consistentes y automatizadas.
